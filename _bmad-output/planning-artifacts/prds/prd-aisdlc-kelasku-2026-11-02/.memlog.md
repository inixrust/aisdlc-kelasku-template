- (event) Create intent; inputs: brief.md, brief addendum.md, docs/intent-kelasku.md (+ forged-idea R4 via addendum)
- (decision) Fast path dipilih user; jawaban baku dry-run dipakai sebagai pengganti tanya-jawab
- (decision) Stakes: alat internal satu lembaga (±5 admin, ±400 peserta/bulan), tim 3 orang, MVP 1 minggu -> PRD 5-8 halaman
- (decision) Riset web tidak dijalankan: pembanding utama adalah spreadsheet+WhatsApp+Google Form; bangun-atau-pakai tetap Open Question dari brief
- (decision) Form factor: web responsif; admin di laptop, peserta di ponsel dan laptop; UI padat seperti panel admin, WCAG 2.1 AA
- (decision) Epik pertama: Kelas & Pendaftaran Berkuota (R1-R3, R7); R4, R5, R6, CSV tetap MUST di MVP sebagai epik berikutnya
- (decision) UJ ringan: dua aktor (Rina admin, peserta bernama) karena alat internal; tanpa seksi persona terpisah
- (decision) Prioritas SHOULD/COULD dari addendum brief dibawa sebagai FR bertanda prioritas, bukan MUST
- (decision) Detail teknis (BEGIN IMMEDIATE, unique index parsial, COUNT dalam transaksi) dipindah ke addendum PRD, bukan FR
- (assumption) Admin boleh membatalkan atas nama peserta; promosi sama (dari brief)
- (assumption) Kenaikan kuota tidak memicu promosi otomatis di MVP (COULD)
- (assumption) Tanggal sesi yang sudah punya catatan kehadiran tidak bisa diubah/dihapus
- (assumption) Halaman status peserta dicari dengan email tanpa password; tanpa batas waktu pembatalan
- (assumption) Deployment: laptop lokal atau satu server kecil milik lembaga, tanpa cloud
- (assumption) Minimal satu sesi per kelas; tanggal sesi unik dalam satu kelas (pilihan paling sederhana)
- (assumption) Kelas tidak dihapus di MVP; tidak ada status arsip (paling sederhana, tidak disebut intent)
